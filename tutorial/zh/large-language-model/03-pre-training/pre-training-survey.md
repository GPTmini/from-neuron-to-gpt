# 预训练技术综述

前面三个部分，我们一步步搭建并预训练了一个 GPT 模型：

* 编码器：（词元嵌入、位置嵌入）把文字变成向量；
* 自注意力：（因果、加权、多头）让词元之间互相理解；
* 预训练：（残差连接、层归一化、随机失活）把模型堆深、训练稳。

整体来讲，我们基本实现了 GPT-2 和 GPT-3 的架构。但是和今天的主流大模型（Llama、Qwen、DeepSeek 等）相比，
从分词到注意力，从模块细节到训练数据，几乎每个环节都已经发生了很大的变化。

这些新的大模型架构，已经很难使用小型的代码和数据展示。本章我们将梳理预训练阶段的前沿技术，建立一章完整的技术地图。
感兴趣的读者可以继续深入研究。

## 技术对比

通过一张对比表，我们来比较一下我们实现的 GPT 和以 Llama 为代表的现代主流大模型有哪些不同：

| 组件      | 我们的 GPT            | 现代主流大模型                          |
|---------|--------------------|----------------------------------|
| 分词      | 字符级，词表 65 左右       | 子词级 BPE，词表 3 万到 25 万             |
| 位置编码    | 可训练的绝对位置嵌入         | 旋转位置编码（RoPE）                     |
| 注意力     | 多头注意力（MHA）         | 分组查询注意力（GQA）、多头潜在注意力（MLA）        |
| 归一化     | 层归一化（LayerNorm），前置 | 均方根归一化（RMSNorm），前置，部分模型加 QK-Norm |
| 前馈网络    | GELU，隐藏层 4 倍       | SwiGLU，隐藏层约 8/3 倍，或者混合专家（MoE）    |
| 线性层偏置      | 有                  | 通常没有                             |
| 随机失活    | 有                  | 通常没有                             |
| 输入输出嵌入  | 各自独立               | 小模型常常共享                          |
| 优化器和学习率 | AdamW，预热余弦退火（WCD）  | AdamW，WCD 或者预热稳定退火（WSD）          |
| 训练数据 | 约 110 万字符的莎士比亚剧本   | 数万亿词元，经过清洗、去重、配比                 |

## 分词

### 字符级分词

我们使用的是**字符级分词**：每个字符是一个词元，词表只有几十个。简单，但是代价也大：

* **编码序列太长**：编码后词元序列太长，而注意力的计算量是序列长度的平方；
* **语义密度低**：单个词元几乎不携带语义信息，模型要先花很多层的学习才能正确地把字符拼成词。

另一个极端是**词级分词**：每个单词是一个词元。序列短了，但是词表巨大，而且无法处理没见过的词（Out of Vocabulary，OOV），
比如新造词、拼写错误、人名等。

### 子词分词

**子词分词**（Subword Tokenization）是折中方案：常见的词保持完整，罕见的词拆分成更小的片段。

* **BPE**（Byte Pair Encoding）：从单个字符开始，不断把语料中出现最频繁的相邻词元合并成新的词元，
直到词表规模达到预定的大小。GPT、Llama 等采用；
* **Unigram**：反过来，从一个很大的候选词表开始，不断删除对似然贡献最小的词元。T5 等采用。

另外值得一提的是 **SentencePiece** 工具库，直接在原始文本上训练，把空格也当作普通字符。同时支持 BPE 和 Unigram，
适合中文、日文等没有空格的语言。

### 字节对编码 BPE

BPE 从字符开始合并：任何文本都可以表示成字节序列，不会出现 OOV。从 GPT-2 开始使用，目前仍然是最主流的分词方案。
目前流行的开源库是 tiktoken。

BPE 分词前通常还有一个**预分词**（Pre-tokenization）步骤：用正则表达式先把文本粗略地切分成单词、数字、标点等，
再在每个片段内部做 BPE，这样可以避免字节合并时跨越单词天然边界。

### 词表大小

词表大小是一个权衡的结果：

* **词表更大**：同样的文本编码后，词元序列更短，注意力和推理成本更低。对中文、代码等非英语文本优势尤其明显。
但是嵌入层和输出层的参数更多，低频词出现机会较少，训练不充分；
* **词表更小**：正好相反，嵌入层和输出层参数少，但是序列更长。

典型的词表大小：
* **GPT-2**：约 5 万；
* **Llama2**：约 3.2 万；
* **Llama3**：约 12.8 万；
* **Gemma**：约 25.6 万。

趋势是越来越大，尤其是为了更好地支持多语言。

### 多模态词元

多模态模型同样需要把图像、音频变成词元序列：

* **连续块嵌入**：例如 ViT，把图像切成块（Patch），每块经过线性投影，直接作为输入向量；
* **离散视觉词元**：例如 VQ-VAE，吧图像量化成离散编码，和文字词元放进同一个词表。

### 嵌入共享

我们的模型中，嵌入层的**词元嵌入**权重和输出层的线性层权重是两个独立的矩阵。但是它们的格式正好是转置关系：
`(词表大小, 嵌入大小)` 和 `(嵌入大小, 词表大小)`。

**嵌入共享**（Weight Tying）让两者使用同一份参数。在词表很大、模型较小的时候，嵌入层和输出层参数占比非常可观，
所以小模型（比如 Gemma、Llama 3.2 等）常常采用。

## 位置编码

### 绝对位置嵌入

我们使用的是**可训练的绝对位置嵌入**：每个位置有一个独立的位向量，加到词向量上。它有两个局限：

* **长度固定**：超出上下文尺寸的位置没有对应的位向量，无法处理超出上下文窗口的文本；
* **绝对位置**：模型学到的是绝对位置，而语言更关心的是词元之间的**相对距离**。

### 位置编码的演进

* **正弦位置编码**（Sinusoidal）：这是 Transformer 论文的原始方案。用不同的正弦、余弦函数生成位向量，不需要训练；
* **可训练位置嵌入**：GPT-2 的方案，也是我们实现的方案；
* **ALiBi**：在注意力分数上直接减去一个和词元距离成正比的线性值，每个头使用不同的线性斜率。不需要训练，也可以处理更长的序列；
* **RoPR**：旋转位置编码，目前最主流的方案；
* **NoPE**：完全不使用位置编码，利用因果掩码实现一定程度的效果。

### 旋转位置编码

**旋转位置编码**（Rotary Position Embedding，RoPE）不是把位向量加到词向量上，而是通过旋转向量来表达位置。

RoPE 对自注意力机制中的**查向量**（Query，$q$）和**键向量**（Key，$k$）顺时针或逆时针旋转一个与该词元位置 $m$ 
成正比的角度 $\theta$。经过旋转后，位置为 $m$ 的查向量 $q_m$ 与位置为 $n$ 的键向量 $k_n$ 做点积运算时，
其结果只取决于两者的相对距离 $m - n$，而与它们的绝对位置 $m$、$n$ 是多少无关：

$$
(R_m q)^\top (R_n k) = q^\top R_{n-m} k
$$

这种设计让模型在计算注意力时，天然地具备了相对位置感知能力，也不需要再把位向量加入词向量。
同时，可以通过数学技巧（比如调整旋转角度的频率）让推理时可以处理比训练时更长的上下文。
Llama、Qwen、DeepSeek 等几乎所有主流开源大模型都采用 RoPE。

## 注意力

自注意力的计算量和注意力分数矩阵的大小，都和序列长度 $n$ 的平方成正比：$O(n^2d)$。上下文从 4K 扩展到 128K，
注意力的计算量增加了 1000 倍。

这是预训练中注意力研究最核心的驱动力：怎么让注意力**更快**、**更省**，或者干脆**绕开**平方复杂度。

### 减少键值头

标准的 **多头注意力**（Multi Head Attention, MHA） ，每个 query 头对应一个独立的 key 和 value。
表达能力强，注意力机制无损，但是显存和带宽消耗大。但是如果让多头共享 key 和 value，混存就能成倍缩小：

* **Multi Query Attention**（MQA）：所有 query 头共享一组 key 和 value；
* **Group Query Attention**（GQA）：query 头分组，每组共享一组 key 和 value；
* **Multi Head Latent**（MLA）：把 key 和 value 压缩成低维的**潜向量**（Latent）。

这些算法的主要动机时减少推理时的 KV 缓存，但是都改变了模型结构，需要在预处理阶段就确定下来。目前主流大模型大多采用 GQA。

### 高效注意力计算

标准注意力需要把注意力分数矩阵写入显存，再读出来做 Softmax 和加权求和，大量时间花在数据搬运上。

现在绝大多数主流大模型（如 Llama、DeepSeek 等），在预训练时都默认启用了 FlashAttention： 
它通过**分块**（Tiling），把 Q、K、V 切成小块，精确控制 GPU 高速缓存（SRAM）和显存（HBM）之间的数据读写，
将内存复杂度从 $O(n^2)$ 降到了 $O(n)$，速度显著提高。

FlashAttention-2 改进了并行和任务划分，FlashAttention-3 针对 Hopper 架构做了进一步优化。

FlashAttention 算出来的注意力矩阵和传统方法完全一样（它是精确计算，不是近似）。
但是在工程上，没有 FlashAttention 带来的工程优化，就没有今天长文本、高效率的现代大模型预训练。

### 稀疏注意力

注意力矩阵的大部分权重其实接近 0，因此可以选择只计算最重要的位置：

* **滑动窗口注意力**：每个词元只关注最近的若干个词元；
* **全局词元**：设置少数词元可以关注，也可以被所有词元关注；
* **局部和全局交替**：多数层使用滑动窗口，少数层使用完整注意力；
* **可训练的稀疏模式**：让模型自己学习关注哪些词元（比如 DeepSeek 的稀疏注意力）。

### 注意力的稳定性

**QK-Norm** 在计算注意力分数之前，先对 Q 和 K 做归一化，防止分数过大导致 Softmax 饱和，使训练更稳定。

## 转换器模块的演进

我们实现的 Transformer 模块是：归一化 → 注意力 → 随机失活 → 残差连接；归一化 → 前馈网络 → 随机失活 → 残差连接。
现代大模型在每个子模块都做了改进。

### 归一化

* **均方根归一化**（Root Mean Square Normalization, RMSNorm）是层归一化的一种有效的简化版。
RMSNorm 直接假设均值为 0，只计算均方根。并且只保留可学习的缩放因子 $\gamma$，去掉平移因子 $\beta$。
计算量更小，效果和层归一化相当，是目前几乎所有主流大模型的选择。

* **前置归一化**：Transformer 论文是把归一化放在残差连接之后。GPT-2 改成放在子层之前（也就是我们采用的做法），
训练更稳定，因为残差通道保持干净。

* **DeepNorm** 调整残差的缩放系数和初始化，可以稳定地训练上千层的 Transformer。

### 前馈网络

* **门控线性单元**（GLU）：前馈网络不再是“线性 → 激活 → 线性”，而是增加一个门控机制：

$$
\text{FFN}(x) = \left(\text{Swish}(x W_1) \odot x W_3\right) W_2
$$

其中 $\text{Swish}(x) = x \cdot \sigma(x)$。

用激活后的一路，去“门控”线性的另一路。这种结构称为**SwiGLU**，效果明显优于 GELU，并成为多数主流大模型的标配；

* **隐藏层权重**：SwiGLU 有 3 个权重矩阵，未来保持参数量不变，权重尺寸从 4 倍缩小为 8/3 倍；
* **混合专家**（MoE）：把每个 Transformer 模块的前馈网络替换成多个**专家**（Expert）和一个路由器（Router）。
路由器为每个词元选出得分最高的 $k$ 个专家，只有被选中的专家参与计算。MoE 让模型的规模由总参数决定，计算量却只由激活参数决定。

### 随机失活

我们在模型中使用 **Dropout** 防止过拟合。但是现代大模型的预训练通常不使用**随机失活**。
因为训练数据通常只过一遍，过拟合不是主要问题。而且**AdamW**的**权重衰减**已经具备防止过拟合的作用。

只有数据量不足、需要重复训练多个轮次的场景（比如我们的模型），随机失活才比较有价值。

## 优化

### 优化器

我们使用的 **AdamW**，也是目前比较常用的优化器。常见的大模型预训练配置包括：

* **Adam 超参数**：$\beta_1 = 0.9$，$\beta_2 = 0.95$；较小的 $\beta_2$ 让模型对近期的梯度更敏感，大规模训练更稳定；
* **权重衰减**：通常 0.1；
* **梯度裁剪**：全局梯度范数（Norm）裁剪到 1.0，防止偶尔出现的大梯度破坏训练的稳定。

### 学习率调度器

我们使用**预热余弦退火**学习率调度器，通过预热和余弦衰减两个步骤，实现学习率增长到峰值，然后衰减的过程。

但是它也有一个确定：必须事先确定总训练步数，不灵活。

**WSD**（Warmup Stable Decay）不需要事先确定训练量：

* **预热**：学习率增长到峰值；
* **稳定**：保持峰值稳定；
* **衰减**：想要停止训练时，才在最后一段（比如 10%）里快速衰减。

## 训练系统

---

本章节，我们梳理了预训练领域的主流技术：

* **效率**：怎样在有限的算力下，学到更多：BPE、RoPE、SwiGLU、MoE、FlashAttention；
* **稳定**：怎样让训练稳定：RMSNorm、QK-Norm、WSD；
* **长度**：怎样处理更长的上下文：RoPE 扩展、GOA、稀疏注意力；
* **规模**：怎样有计划地扩大：缩放定律、并行策略、训练系统。

我们从零实现的 GPT 模型，是这些技术的起点。Transformer 的基本结构，至今没有改变。目前后续的改进，都是在这个骨架上打补丁。
