一套从单个神经元出发，只用 NumPy 一步步手搓出 GPT 的教程。

不依赖 PyTorch、TensorFlow 等深度学习框架：自动求导、网络层、优化器、 注意力、Transformer、训练、推理、微调，全部从零实现，并配有逐步讲解的 Jupyter Notebook。

教程特点

  • 零框架依赖：只用 NumPy，从张量、计算图、反向传播开始，每一行代码都能读懂。
  • 循序渐进：从一个神经元，到 GPT、监督微调（SFT）和直接偏好优化（DPO），每章只引入少量新概念。
  • 讲解与代码同在：每章都是一个可以独立运行的 Notebook，多数章节末尾附有课后练习。
  • 纯 CPU 运行：不需要 GPU，使用较小模型观察训练、推理和微调的完整过程。

教程内容

第一部分：神经网络基础

从线性回归、多层感知机和反向传播开始，逐步实现网络层、损失函数、优化器，并学习循环神经网络。

第二部分：大语言模型基础

从词元嵌入和注意力机制出发，逐步构建 Transformer / GPT，进一步学习预训练、推理、监督微调和直接偏好优化。

教程代码基于 Python 和 NumPy。建议按 Notebook 编号顺序阅读，并在本地运行示例代码。
